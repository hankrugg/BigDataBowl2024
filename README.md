# NFL Big Data Bowl

## Overview
This is a collection of useful functions that can be used for the NFL Big Data Bowl. The goal was to create a dataset that is clean and generic enough that it would be
able to be used regardless of the year's topic.

## Files & Structure
- `BigDataBowl.ipynb` - Main Jupyter Notebook with code and analysis.
- `cleaning.py` - Code to help clean the datasets.
- `constants.py` - Constants (just the team color schemes).
- `preprocessing.py` - Preprocessing and feature engineering.
- `visualizations.py` - Helpful prebuilt visualizations.
